Dependency proof is generated at submission time.

Required evidence:
1. python3 --version (must be the pinned Python 3.14 toolchain used for release)
2. python3 -m pip list --format=freeze (runtime manifest is empty; any packages shown here are tooling/environment only)
3. grep/import audit showing sealbox.py imports stdlib modules only
4. two consecutive build hashes of build/sealbox.pyz

Example release commands:
  python3 --version
  python3 -m pip list --format=freeze
  python3 -m py_compile sealbox.py
  ./build.sh
  cp build/sealbox.pyz build/sealbox.first.pyz
  ./build.sh
  sha256sum build/sealbox.first.pyz build/sealbox.pyz
