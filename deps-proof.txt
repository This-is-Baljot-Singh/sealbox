sealbox dependency proof
========================

Release procedure (run on the final Python 3.14.x submission machine):

  python3 --version
  cat requirements.txt
  python3 -m pip list --format=freeze
  ./release_check.sh

Interpretation:
- requirements.txt MUST be empty.
- pip itself may appear in the environment; pip is development/environment tooling, not a sealbox runtime dependency.
- release_check.sh performs the runtime import audit against sys.stdlib_module_names and executes the artifact with python -I -S.
- The final SHA-256 printed by ./build.sh is the hash of the exact submission artifact.

Final release values must be recorded from the actual submission machine. Do not copy hashes from another environment.
